🧩 TETWIST Build 1.1 🎮
✨ UI • Scoring • Modifiers • Persistence • Logo Polish

TETWIST Build 1.1 is a major polish and feature update focused on improving the game's identity, progression feedback, and overall UI experience.

🏆 Persistent High Score

Added a persistent High Score system that survives between game sessions.

💾 High score is saved to highscore.dat

🔄 High score is automatically loaded when the game starts

📈 Only scores higher than the current record are saved

🧮 Current score and high score are displayed separately

🔢 Scores use formatted numerical displays for a cleaner arcade-style look

🎯 Improved Score & Progression UI

Added clearer visual feedback for the player's current progress.

⭐ SCORE display

🏆 HIGH SCORE display

📊 LINES counter

📶 LEVEL indicator

🔢 Consistent number formatting across the interface

🎮 Better spacing and organization around the playfield

🧰 HOLD & NEXT PIECE UI

Redesigned the piece preview areas to have a more consistent visual identity.

📦 HOLD PIECE

4×4 preview grid

Consistent 160×160 display box

EMPTY indicator when no piece is held

PRESS C TO HOLD instruction

➡️ NEXT PIECE

4×4 preview grid

Matching 160×160 display box

Aligned with the HOLD PIECE section

Cleaner and more consistent placement

⚡ Modifier System UI

Expanded the modifier interface with clearer visual feedback.

🟢 BUFF

A visual meter tracks the player's current Buff points.

🔴 DREAD

A separate meter tracks Dread progression.

📜 RECENT MODIFIERS

Added a history display showing the most recently triggered modifiers.

Each entry displays:

1. Modifier Name - BUFF
2. Modifier Name - DEBUFF

Modifier history is limited to the 5 most recent modifiers.

🔄 Modifier History Reset

Fixed an issue where the Recent Modifiers list could carry over into a new game.

Modifier history now properly resets when InitGame() starts a new game.

🎨 TETWIST Logo

Added a dedicated TETWIST logo area to the bottom-left portion of the UI.

The logo now features:

🖤 Dark rounded background

▫️ Light border

🔤 Large individual letters

🌈 Different colors for each letter

✨ Bright neon/rainbow-inspired color palette

🔀 New randomized colors whenever a new game begins

🌈 Dynamic Letter Colors

Each letter of:

T E T W I S T

gets its own randomly selected color.

The color palette uses bright arcade-style colors such as:

🔴 Red
🟠 Orange

🔵 Blue / Sky Blue
🟣 Violet
